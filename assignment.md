# GNSS Signal Processing — Take-Home Assignment

## Background

You are provided with a NetCDF file containing a simulated GNSS baseband IQ recording. The file is self-describing. Inspect its structure and metadata to determine how to interpret and process the observations.

The recording contains a superposition of multiple GPS L1 C/A signals, each corresponding to a different PRN. All transmitted PRN sequences have been modified by unknown binary sequences generated by a common rule, applied chip-by-chip in each PRN's own code coordinates.

## Your task

Develop an algorithm to:

1. Identify the PRNs present in the recording and estimate the signal parameters needed for subsequent processing.
2. Recover the binary modification sequence(s) applied to the PRNs.
3. Determine and explain the mathematical structure or rule underlying the modification.
4. Demonstrate quantitatively that your recovered sequence(s) explain the received observations.

You are not given the number of PRNs, the number of modified chips, or the structure of the modification.

## Deliverables

- Working Python or MATLAB code.
- The recovered binary modification sequence(s).
- An explanation of the underlying mathematical pattern.
- A concise description of your algorithm and its mathematical reasoning.
- Quantitative evidence supporting your solution.

You may use standard scientific computing libraries and AI-assisted development tools. You must be able to explain and justify your solution.

## Evaluation

Evaluation will emphasize signal-processing reasoning, correctness, and the ability to exploit common structure across multiple signals.
